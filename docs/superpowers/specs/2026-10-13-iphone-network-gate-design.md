# 手机网络配置与镜像带做关卡

用户要求把小火箭全局路由纳入必检项，并强调新手应优先由 Codex Computer Use 操作 iPhone 镜像导入节点；镜像不可用时尽可能排查修复，只有确实无法操作时才改用其他工具或手动带做。

## 触发与流程

2026-10-27 按现行主流程修订：电脑网络与 AdsPower 验收后，必须进入手机配置、时区与定位、手机网络验收，再完成手机登录和订阅；日常主要使用电脑也按此流程交付。

流程以现行 `scripts/workflow_definition.py` 为准：手机代理 → 电脑／手机时区与定位 → 手机网络独立验收 → 支付准备 → 官方 App／安卓官网 → Google 登录 → 手机订阅与权益确认。iPhone 按本设计准备与排查镜像能力，安卓使用对应章节。

客户端的购买、密码、验证码、Face ID 与系统授权由用户完成。导入使用用户本机节点资料，不将链接、密钥或私人数据放进公开文件。

## 镜像失败处理

依据当前 Apple 官方说明和实际页面逐项核对硬件、系统和地区支持、同一 Apple 账户及双重认证、Wi-Fi／蓝牙、设备距离和锁定状态、连接授权及工具操作权限，按报错修复并重试。确认具体不支持或排查仍无法操作时记录原因和尝试，优先采用其他可用手机操作工具，最后才逐步手动带做。用户明确要求手动时尊重其选择。不盲目重置设备，不把镜像失败当成跳过网络验收的理由。

## 验收边界

小火箭「代理」将 VPN 接管且未被排除的流量送到所选节点，最接近电脑 TUN 加全局代理。「配置」按规则分流，「直连」直接连接，「场景」按场景切换，不能直接替代默认要求。普通 VPN 关闭后可能恢复原网络；分别记录节点故障与 VPN 关闭行为，不承诺永久断网保护。手机浏览器出口不能独自证明 App 请求路径，缺失结果记未验证。

适用项未通过或未验证时先修复／补检，不默认继续手机注册、登录或订阅。用户暂停时保留当前进度，恢复后继续补齐手机验收。电脑结果不能代替手机；Wi-Fi 结果不能代替蜂窝；当前不使用的网络标注切换前补检。各项证据只存 `.local/`，禁止私人 IP 或凭据进入发布。
