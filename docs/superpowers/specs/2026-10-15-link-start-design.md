# 链接交付实时下载

用户已确认的目标：发公开仓库链接开始带做时必须下载最新完整版本，不能复用旧副本。

选择专用 start 命令，区别于现有日常 check/apply。只加文字提醒不足以验证实际文件；每次普通回复重新下载会干扰带做，所以只在链接启动时执行。

入口实时取得 main 和其中的脚本，检查后执行。start 再锁定 main，下载该提交 ZIP，对照远端 manifest 和版本校验，重查 main，必要时最多重试三次。成功发布到新的本地目录并返回版本、提交、目录。失败暂停带做。保留旧目录，可迁移 .local 进度但排除缓存与启动记录。成功后重新读新目录正文，显示版本。

范围为公开仓库；不变更私有领取或其他交付后台。日常调用仍使用原有更新提醒机制。

验证：缓存不得参与启动；旧进度保留；坏文件、错误清单、断网不得 ready；main 变更重试有界；真实发布后从 GitHub 下载验证版本、规则与清单。脚本校验能证明文件一致，不能证明 AI 永远遵守指令，故入口和实际目录均明确记录。
