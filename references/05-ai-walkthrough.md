# AI 从零带做指南｜Claude 网络、账号与订阅

带做先运行 `python3 scripts/workflow.py next`，按控制层返回的当前阶段读取对应小节，取得实际结果后提交控制层推进（详见[统一交付控制层](17-workflow-controller.md)）。

## 1. 启动与带做节奏

- **链接启动与更新**：客户发来公开仓库链接时，先按[链接交付启动流程](12-latest-start.md)下载并校验最新完整包，再从新目录直接带做。本地日常继续时，沿用 `workflow.py` 自动检查更新结果，发现新版在首个实质回答末尾展示 `update_notice`，客户同意后更新并保留 `.local/` 进度。
- **按阶段推进**：首次带做按[开场说明与客户阅读版](13-reader-guide.md)先问设备封禁经历，有封禁经历先按[旧登录残留处理](04-recovery.md#有封禁经历时先处理旧登录残留)安排适用清理；随后依次完成设备搭配与 PDF 阅读版说明 → Google 账号准备 → VPS → 服务端 → 电脑网络 → AdsPower → 手机小火箭 → 时区定位 → 手机网络验收 → Apple 账户与礼品卡准备 → 官方 App → 手机 Google 登录 → Pro 订阅与权益确认。已完成部分复用原记录，直接从缺项继续。
- **每轮怎么带**：有工具且已授权时连续完成可代做动作并直接验收；需要客户手动操作时，每轮合并给 2～3 个相连动作，写清楚下面四项：
  - **当前进度**：所在阶段与当前小目标。
  - **现在这样做**：具体软件／页面、点击位置与填写内容（命令标明本机终端或远程 VPS 终端）。
  - **完成后应该看到**：明确的页面或输出标志。
  - **做完告诉我**：需要反馈的截图或口述结果（密码、验证码、付款由客户在自己页面完成）。
- **卡住时**：一次只排查一个点，用户说“不会／找不到”就把动作再拆细并用 `workflow.py guide` 重发对应原图。

## 2. 全流程各阶段核心操作

### 2.1 购买与部署 VPS

1. **选型与图解**：按 `workflow.py policy` 推荐直接推进（当前为搬瓦工 USCA_9 2 GB 季付，恢复常规核对时按 DMIT 月付 → 搬瓦工季付顺序核对，见[库存核对](18-vps-stock.md)）。机房默认洛杉矶，新购系统统一选 **Debian 12**。选定搬瓦工时，一次展示[搬瓦工注册与购买图解](09-vps-purchase.md)的四张注册图、一张套餐图和两份 PDF，客户完成注册付款并确认服务器开通。
2. **部署与导出节点**：使用 `workflow.py run` 依次执行 `server_preflight`、`server_deploy`（或已有本脚本节点用 `server_export`），安装固定组合（3x-ui v3.10.2、Xray 26.7.28、REALITY Cloudflare SNI），读回运行状态并导出节点到 `.local/network/node.txt`。

### 2.2 配置电脑网络（全流程仅测 1 次断线）

按[网络教程](01-network.md)（Windows 见[Windows 专章](10-windows.md)）执行：
1. **保住旧 VPN 单独测通**：保留旧 VPN 为 Codex 联网；Mac 用 `download_karing` 安装校验固定版本 Karing `1.2.25.2802`（Windows 用 v2rayN），导入节点后通过 `probe_proxy` 经本机 HTTP 入口测通新节点。
2. **交接与复验**：先向客户展示恢复旧 VPN 的具体步骤，再关闭旧 VPN 接管、开启新客户端 **系统代理关闭 + TUN 开启 + 全局代理**（保留本机 HTTP 入口给 AdsPower），运行 `probe_system` 确认出口一致并请客户发一句“继续”确认 Codex 回复正常。
3. **电脑断线测试**：在 `computer_network` 阶段完成 1 次受控断线测试并确认自动恢复（后续 AdsPower 与手机阶段不再做断线测试）。
4. **故障直接修复**：Mac Karing 握手异常直接按[网络教程第十节](01-network.md#十karing-reality-握手失败)顺序修复（`mixed → gvisor` → 校正参数与时间 → 应用固定 REALITY 组合）；Windows HTTP 已通但开 TUN 回环按[Windows 第 6.1 节](10-windows.md#61-http-测通tun-后反复连接-vps)排查。

### 2.3 配置 AdsPower 浏览器（写死免费版，不做断线测试）

按[浏览器与 iPhone 章节](02-browser-iphone.md)第 1 节执行：
1. 首次进入先说明 Claude 桌面版、Claude Code 与 AdsPower 的各自用途，并展示三张 AdsPower 教程原图与三站检测链接。
2. **直接使用 AdsPower 免费版**，点左上角「新建环境」手动配置（无需付费 API）。点击「确定」前一次核对完：本机 HTTP 代理入口（点击检查代理通过）、WebRTC 禁用、地理位置禁止、时区洛杉矶、硬件噪音全关、**WebGL 元数据／WebGPU／CPU／内存全部选真实**。
3. 打开新建环境，验收实际出口、IPv4／IPv6、DNS／WebRTC、时区语言，记录 NetCoffee（约 ≥80）、Ping0（<30，优先 <25，留存脱敏截图）和 Scamalytics（<10）三站结果，达标即直接进入手机阶段。

### 2.4 手机小火箭、时区定位与手机网络验收（不做断线测试）

1. **前置说明与锁死小火箭**：进入 `phone_proxy` 主动讲清“手机只用于首次登录和 Apple 礼品卡内购、日常回电脑用、下一步立刻统一电脑／手机／AdsPower 时区”。iPhone／iPad 统一使用 **Shadowrocket（小火箭）**，Mac 优先尝试 iPhone 镜像（桌面控制首次报错在核对权限或重启一次后仍崩溃，立即切手动合并步骤），Windows 按图解手动带做。导入同一节点，全局路由选「代理」并开启 VPN。小火箭全局超时优先按[2.2.1 节](02-browser-iphone.md#221-小火箭全局超时先试-chrome-140)试 `Chrome 140` TLS 指纹；仅微信发图异常按[2.2.3 节](02-browser-iphone.md#223-节点可用只有微信图片打不开)切「配置」模式配微信直连。
2. **统一时区与定位**：连上后询问一次“跟随节点（推荐）／台北”，按[2.3 节](02-browser-iphone.md#23-电脑和手机时区定位设置)完成电脑、手机与 AdsPower 时区统一及对应平台的定位设置并复查。
3. **手机网络验收**：在手机浏览器独立验收实际出口（与电脑一致）、NetCoffee／Ping0／Scamalytics 三站分数、IPv6／DNS、排除路由与所用 Wi-Fi／蜂窝网络（不做断线测试）。安卓用户验收后进入[安卓官网 Google Pay 分支](11-android-web-pay.md)。

### 2.5 Apple 账户、礼品卡充值与手机订阅 Pro

1. **核对美区 Apple ID 与等待安排**：按[Apple 章节](03-apple.md)确认账户来源（`self_used`／`newly_registered`／`purchased`），没有账户时并列给出自注册与购号渠道（[出海91](https://chuhai91.cc)／[xintaikeji](https://xintaikeji.eu.org/)）。新注册与新购买统一展示 🔴 加粗两日等待提醒：仅在 App Store 登录（绝不登 iCloud），从本人手机首次 App Store 登录起正常使用约两天再充值订阅；客户明确选择现在继续时记录选择推进。购买受限立即转[人工支持流程](07-apple-purchase-support.md)。
2. **支付宝优先买礼品卡并兑换**：等待就绪或客户选择继续后，需要买礼品卡首推支付宝，直接调用 `guide --topic gift_alipay` 展示备忘录直达小程序链接与原图，兑换余额后多留一点税费余量。
3. **下载官方 App、Google 登录并订阅 Pro**：保持手机节点开启，下载 Anthropic 官方 Claude App（核对开发者并检查请求路径），用准备好的 Google 账号登录（遇两步验证再次给出 `https://2fa.run/` 与原取码回填图），升级选择 **Pro**（20 美元／月参考价）完成苹果余额支付。
4. **确认权益并收尾**：确认 App Store 订单和当前手机账号的 Pro 权益均已生效，在对话直接展示下方收尾说明，提交 `handoff_explained=true` 结束交付。

## 3. 需要博主帮助时

同一问题经针对性排查仍未解决时，整理设备、当前阶段、报错、已尝试步骤和待确认问题（去掉 IP、邮箱、密码、密钥等隐私），交给用户自行发给博主。

## 4. 订阅完成后必须在对话中展示

> **手机订单和当前账号的 Pro 权益已确认。**手机主要用于登录和订阅，日常在电脑的 Claude 桌面端或 Claude Code／CLI 使用，登录刚才同一个 Google 账号。需要网页登录或授权时，将相关链接放到已配置的 AdsPower 环境完成，再回到桌面端或 CLI。
>
> **使用经验提醒**
> - 可以把每五小时额度约用到 70% 作为个人使用节奏建议，留出余量更稳。
> - 发送项目或资料前，留意内容里是否包含不必要的精确定位信息，先去掉再分享。
> - 涉及生物医药、网络安全等专业话题时，按平台规则正常讨论即可。
>
> 遇到问题先问 Codex；仍需人工帮助时，让它整理当前步骤、报错和已尝试的办法，再把诊断说明发给我们。也可以让 Codex 定位 PDF 对应章节和页码。
