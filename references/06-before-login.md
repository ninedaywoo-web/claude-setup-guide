# 注册或登录 Claude 前，先检查一遍

电脑网络与 AdsPower 验收完成后，直接接续手机小火箭、时区定位与手机网络验收；全部适用项通过后，iPhone 在官方 Claude App 用 Google 登录，安卓按[官网 Google Pay 指引](11-android-web-pay.md)在手机浏览器登录。

## 给用户看的说明

> 确认以下几项都已配好，即可进入账号登录与订阅：
> - **电脑网络**：系统代理关闭、TUN 开启、全局代理指向目标 VPS 节点，本机 HTTP 入口保留给 AdsPower，且电脑网络阶段已完成 1 次断线测试。
> - **AdsPower（免费版）**：新建独立环境已打开，走本机 HTTP 入口，WebRTC 禁用、地理位置禁止、硬件噪音关闭且 CPU／内存为真实值，实际出口、IPv6／DNS 和三站评分均已达标（浏览器阶段不做断线测试）。
> - **手机小火箭**：导入同一服务器节点，全局路由设为「代理」并开启 VPN，手机浏览器独立核对实际出口、三站评分（NetCoffee 约 ≥80、Ping0 <30 优先 <25、Scamalytics <10）、IPv6／DNS 和排除路由（手机阶段不做断线测试）。
> - **三端时区与定位一致**：电脑、手机和 AdsPower 统一为所选时区（推荐跟随节点城市，也可选台北）并关闭自动时区；Mac 关闭系统服务「设定时区」（定位总开关保原状、禁止网页位置权限），Windows 和手机关闭定位总开关。

## AI 验收清单

手机节点连上后，先按[2.3 节](02-browser-iphone.md#23-电脑和手机时区定位设置)完成时区与定位设置，再逐项核对下表（已完成且设置未变的记录直接复用）：

| 检查项 | 核对标准 |
| --- | --- |
| 电脑接管与断线 | 系统代理关闭、TUN 开启、全局代理固定走目标 VPS，本机 HTTP 入口可用；电脑网络阶段已完成 1 次断线测试并通过。 |
| 三处节点一致 | 电脑客户端、AdsPower 经本机 HTTP 的出口、手机小火箭的出口均为同一 VPS 线路。 |
| AdsPower 免费版 | 环境已保存并打开，优先使用本机 HTTP 入口，WebRTC 禁用、地理位置禁止、硬件噪音全关且 WebGL 元数据／WebGPU／CPU／内存为真实，实际出口、IPv6／DNS 与三站评分达标（不做断线测试）。 |
| 手机小火箭与网络 | iPhone／iPad 统一使用 Shadowrocket（小火箭），全局路由为「代理」且 VPN 已连接；手机浏览器实测出口与电脑一致，NetCoffee／Ping0／Scamalytics 三站、IPv6／DNS、排除路由和所用 Wi-Fi／蜂窝网络均已核对（不做断线测试）。 |
| 三端时区与定位 | 电脑系统、手机系统与 AdsPower 实际时区规则一致（节点城市或台北），自动时区均关闭；Mac 关闭系统服务「设定时区」且网页定位禁止，Windows 与手机关闭定位总开关，返回日期与时间页复查确认。 |
| 三站参考分 | [NetCoffee](https://ip.net.coffee/claude/) 约 ≥80、[Ping0](https://ping0.cc/) <30（优先 <25，留存脱敏截图）、[Scamalytics](https://scamalytics.com/ip) <10；电脑与手机各自独立记录，达标即继续（79／35 等轻微偏离直接推进，大幅偏离先复查）。 |

排查指引：仅微信发图异常按[2.2.3 节](02-browser-iphone.md#223-节点可用只有微信图片打不开)切「配置」配微信直连；改过端口或切配置失联按[2.2.2 节](02-browser-iphone.md#222-断线测试后恢复端口手机仍无法联网)恢复；其余小火箭全局超时优先按[2.2.1 节](02-browser-iphone.md#221-小火箭全局超时先试-chrome-140)试 `Chrome 140`。

检查完成后输出简短汇总表（`检查项 | 状态 | 结果`），公网 IP 脱敏后写入 `.local/progress.md`。

## 登录前衔接脚本

统一通过[控制层](17-workflow-controller.md)运行 `python3 scripts/workflow.py next` 并提交各阶段观察。全部适用项齐全后，程序自动衔接[Apple 账户检查与充值](03-apple.md#充值和订阅前先确认-apple-账户情况)（老号复用、新号展示约两天等待安排），就绪后保持手机节点开启，下载官方 Claude App、Google 登录并订阅 Pro。
